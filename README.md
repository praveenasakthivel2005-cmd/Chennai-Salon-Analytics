# 💇 Chennai Salon Booking & Business Analytics Dashboard

## 📌 Project Overview

The **Chennai Salon Booking & Business Analytics Dashboard** is an interactive Business Intelligence project developed using Microsoft Power BI.

The main objective of this project is to analyse salon booking data and generate meaningful business insights related to appointments, revenue, customers, cancellations, and staff performance.

This project helps understand salon business performance through interactive dashboards, visualizations, KPIs, and data analysis.

## 🎯 Project Objectives

- Analyse total salon bookings and appointment trends.
- Monitor total revenue and service-wise revenue.
- Understand customer behaviour and repeat customers.
- Analyse appointment cancellations and no-show records.
- Evaluate staff productivity and performance.
- Identify business trends across different Chennai areas.

## 🚀 How to Run the Project

1. Download or clone this GitHub repository.
2. Download and install Power BI Desktop.
3. Open the `.pbix` file using Power BI Desktop.
4. If required, update the dataset file path in Power Query.
5. Click Refresh to load the data.
6. Explore all four interactive dashboard pages.
